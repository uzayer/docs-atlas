Every term used across these docs is defined once, here. Other pages link back to this page rather than redefining a term inline.

## Project

A folder Atlas works in, plus its `.atlas/` directory.

## Organisation

An online account container owning projects, with members and roles.

## Agent

A coding agent Atlas drives: a built-in agent, one installed from the agent registry, or Atlas's native agent.

## Session

One agent conversation, recorded and resumable.

## Checkpoint

The link between a session and the commit containing its work.

## Timeline

The record of your sessions and the checkpoints they produced.

## Shared memory

On-device index every agent reads from and writes to.

## Agent preferences

A rule or preference Atlas distils from your instruction files and memory, and surfaces for editing.

## Skill

A `SKILL.md` file scoped globally or per project.

## Pack

An installable bundle of skills, commands, hooks, subagents, rules, and scripts.

## Knowledge base

Markdown notes in `.atlas/knowledge/`.

## Mention

`@` anything: files, folders, symbols, branches, notes, papers, sessions, and more.
