Once you're past your first [session](/docs/getting-started/concepts#session), most of Atlas is faster from the keyboard.

![The @ mention picker open in the composer](/screenshots/placeholder.svg)

## Shortcuts

| Shortcut | Action |
| --- | --- |
| `⌘O` | Open a project |
| `⌘K` | Command palette |
| `⌘P` | File picker |
| `⌘⇧F` | Search |
| `⌘T` | New agent chat |
| `⌥/` | Cycle agent |
| `⌘N` | New untitled editor |
| `⌘⇧T` | New terminal tab |
| `⌘J` | Toggle terminal |
| `⌥J` | Open knowledge base |
| `⌘⌥J` | Toggle chat sidebar |
| `⌘B` / `⌘⇧B` | Toggle left / right panel |
| `⌘⌥B` | Toggle bottom panel |
| `⌘1`–`⌘9` | Jump to tab by index (`⌘9` = last tab) |
| `⌘W` | Close tab |
| `⌘⇧[` / `⌘⇧]` | Cycle tabs |
| `⌘\` | New split column |
| `⌥;` / `⌥'` | Focus adjacent split |
| `⌥W` | Close focused split |
| `⌥Z` | Zen mode |
| `⌘,` | Settings |
| `⌘=` / `⌘-` / `⌘0` | Zoom in / out / reset |

## `@` mentions

Type `@` in any composer to pull something into context without leaving the keyboard:

- **file** / **folder**: anything in the project
- **symbol**: a function, class, or other code symbol
- **note**: a [knowledge base](/docs/getting-started/concepts#knowledge-base) note
- **component**: a command, subagent, or rule installed from a [pack](/docs/getting-started/concepts#pack)
- **repo**: a cloned GitHub repository
- **project**: another project
- **paper**: a paper you've added in Research
- **branch**: a git branch
- **past message** / **past session**: anything earlier in this session, or an earlier one

Type `~` instead of `@` to open the same picker scoped to just the knowledge base, the same shortcut the notes editor uses.
