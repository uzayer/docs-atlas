Atlas has no setup wizard. You open a folder, and you're working.

## Open a project

Press <Kbd>⌘O</Kbd> or click **Open Folder**, and pick a folder on disk. That folder becomes a [project](/docs/getting-started/concepts#project), and Atlas doesn't ask you to configure anything first: no prompts, no trust dialog.

The next time you launch Atlas, that project shows up in the recent-projects list on the welcome screen.

Atlas doesn't create a `.atlas/` directory up front, either. Each feature (memory, knowledge base, canvases, and the rest) creates its own piece of it the first time you use that feature. The one thing that happens automatically is quiet: Atlas adds `.atlas/` to your project's `.gitignore` if it isn't already there.

## Pick an agent

Atlas opens on a chat panel with Atlas Agent ready to use. Click the agent icon in the composer to switch to anything else you have installed from the ACP registry.

You can also press `⌥/` to cycle through them without touching the mouse. Each one is an [agent](/docs/getting-started/concepts#agent) driven the same way, against the same project.

Open **Settings → Agents** to install an external agent. The composer also offers several popular registry entries as one-click installs. Both routes create the same registry-backed installation; Atlas does not ship a separate built-in copy of any external agent.

The connected agent tells Atlas which sign-in methods, models, modes, and other controls it supports. Use the repository or website on its registry card when setup is specific to that agent.

## Turn on session capture

Select the project name in the title bar, keep **Local**, and select **Enable**. This is the one switch Atlas asks for. It records the project's agent work on this machine and imports your earlier Claude Code sessions. See [Session capture](/docs/source-control/capture).

## Run a session

Send a message. That conversation is a [session](/docs/getting-started/concepts#session), recorded and resumable later from the same panel.

When the agent edits files and commits, you don't have to do anything to preserve the context behind that commit. With capture on, Atlas links the commit back to the session that produced it.

## See the checkpoint

That link is a [checkpoint](/docs/getting-started/concepts#checkpoint). Open the Git panel and select the commit: it shows "Produced by 1 session," and clicking it jumps back into the session in your [timeline](/docs/getting-started/concepts#timeline).

The timeline header also has a Recent Checkpoints list you can search directly.
