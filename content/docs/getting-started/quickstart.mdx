This page takes you from a fresh install to a session your teammates can read. The first half works on your own, with no account. The second half connects you to your team.

## 1. Install Atlas

Download Atlas for macOS, Windows or Linux and open it. See [Install](/docs/getting-started/install) for the details per platform.

## 2. Add a project

Press <Kbd>⌘⇧N</Kbd> (**Add project…**) or select **Open Folder** on the welcome screen, then pick a folder. That folder becomes a [project](/docs/getting-started/concepts#project) in the sidebar. Atlas asks you to configure nothing first.

You can also add projects from the **+** beside the organisation name in the sidebar, which lists your recent projects. On macOS, `atlas .` from a terminal opens the current folder (see [Install](/docs/getting-started/install)).

Atlas keeps its per-project data in a `.atlas/` directory and adds `.atlas/` to the project's `.gitignore` for you.

## 3. Add an agent

Press <Kbd>⌘T</Kbd> to open an agent chat. Select the agent icon in the composer to pick an agent.

A fresh install comes with Atlas Agent only, and Atlas Agent needs a synced organisation (step 7). To start right away, install an agent from the [ACP registry](/docs/agents/registry): the agent picker offers popular ones such as Claude Code, Codex, OpenCode and Cursor as one-click installs, and **Settings → Agents** lists the full registry.

The agent you install tells Atlas how it signs in. Follow its prompt, or the instructions on its registry card.

Press <Kbd>⌥/</Kbd> to cycle through your installed agents without leaving the keyboard.

## 4. Turn on session capture

Select the project name in the title bar, or press <Kbd>⌘⌥C</Kbd>, to open **Session capture**. Under **Where sessions are stored**, keep **Local** and select **Enable**.

Local capture records the project's agent work on this machine, with no account and no network. It also brings in the Claude Code sessions you already ran in this folder. See [Session capture](/docs/source-control/capture).

## 5. Run a session

Send the agent a message. That conversation is a [session](/docs/getting-started/concepts#session), recorded as it happens and resumable later from your chat history.

When the agent's changes are committed, by the agent, by you in Atlas, or from a terminal, Atlas links the commit back to the session. You don't do anything extra.

## 6. See the checkpoint

That link is a [checkpoint](/docs/getting-started/concepts#checkpoint). Open Source Control (<Kbd>⌘⇧B</Kbd>), go to **History** and select the commit. It shows **Produced by 1 session**, and selecting the session opens it in the [timeline](/docs/team/timeline).

## 7. Sign in and join your organisation

Select **Sign In** from the account control in the title bar. Atlas opens your browser; approve the device there and come back. See [Your account](/docs/team/accounts).

Then get into a synced [organisation](/docs/team/organisations):

- **Start one.** Open the organisation switcher at the top of the sidebar, select **Create organisation…** and choose **Cloud**. Or select **Turn on sync for Personal…** to sync the local organisation Atlas made for you.
- **Join one.** Accept the invitation a teammate sent you. The organisation then appears in the switcher.

A synced organisation turns on team chat, the shared timeline, Cloud capture and Atlas Agent. If the composer says your organisation doesn't have AI grants, an admin has to give it AI access first. See [AI access & spend](/docs/team/ai-access).

## 8. Make the project Cloud

Open **Session capture** again (<Kbd>⌘⌥C</Kbd>). Beside **Local**, select **Sync** to open **Promote to Cloud**.

- **Create** publishes the project to your organisation under a slug you choose. Leave **Restrict to named members** off to let every member read it.
- **Connect** joins a project a teammate already published from their copy of the same repository.

Select **Continue**. Atlas shows exactly what it will send, how many sessions, from when, and how many secrets it redacted, before anything leaves your machine. Confirm to finish.

## 9. See it on the team timeline

Select **Timeline** at the top of the sidebar. Your sessions now sit beside your teammates', each with its author. Live sessions are flagged while their agent is still working, and anyone in the organisation can comment on a session, a message, a tool call or a checkpoint.

Your teammates see the same board in their Atlas and in the web app at [app.tryatlas.cc](https://app.tryatlas.cc). See [Timeline](/docs/team/timeline).
