The [knowledge base](/docs/getting-started/concepts#knowledge-base) is a set of markdown notes stored in your project's Atlas directory. It's the deliberate counterpart to [memory](/docs/features/memory): memory is what Atlas infers, and this is what you decide to write down.

It lives in the left panel, alongside the [file tree](/docs/features/explorer).

![A knowledge base note open with its sidebar and inspector](/screenshots/placeholder.svg)

## Writing

Notes are edited in a block editor rather than as raw markdown: headings, lists, and the usual structure, with an outline you can jump around. `⌘S` saves.

Each note can carry properties, an icon, and a cover. A sidebar holds the tree of notes; an inspector (`⌘'`) shows the current note's details, and the sidebar toggles with `⌘;`.

Notes link to each other, and a note shows what links back to it.

## Using a note as context

Type `@` in the [composer](/docs/features/chat) and knowledge base entries are one of the things you can [mention](/docs/getting-started/concepts#mention). The note's content is appended to your message as a context block, so you can see exactly what the agent was handed.

Notes are also indexed into memory, so relevant ones can surface on their own without you naming them.
