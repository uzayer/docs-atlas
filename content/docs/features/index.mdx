These surfaces exist to make agent work reviewable: every checkpoint links a session back to the commit it produced, so the record of what an agent did and why is never more than a click away.

Atlas is also an IDE, so a lot of it will be familiar: a file tree, an editor, a terminal, a source-control panel. What's different is that an [agent](/docs/getting-started/concepts#agent) is working in the same window, and every one of those surfaces is shaped by that.
