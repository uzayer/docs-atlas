Atlas can install Claude Code, help you sign in, and reopen its saved conversations.

## Install and sign in

Pick Claude Code in the composer. If it is missing, select **Install Claude Code** and Atlas runs Anthropic's official installer while showing its output.

You need Node.js. Atlas reads your login shell's `PATH`, so it finds Node installed with nvm, fnm, volta, asdf, or Homebrew even when you launch Atlas from the Dock.

When Claude Code needs authentication, select **Sign in to Claude Code** and finish one of the methods it offers. Atlas checks again when you return.

## Choose a model or mode

Use the composer to select the model and mode Claude Code exposes for this session. You can change modes while the session is running.

## Resume your work

Claude Code stores transcripts in `~/.claude/projects/`. Atlas reads them when you reopen a session, so the real conversation is ready before the interface reconnects to the agent.

Atlas also records the session in your [timeline](/docs/source-control/timeline) and connects its commits to [checkpoints](/docs/getting-started/concepts#checkpoint).

<Callout type="warn">
  If you launch Atlas from a Claude Code shell, Atlas clears Claude Code's anti-nesting variable before starting the agent. That is why this path behaves differently from starting it in a fresh shell.
</Callout>
