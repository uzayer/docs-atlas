Choose an agent, point it at your project, and keep the work in one shared record. Atlas keeps sessions, [checkpoints](/docs/getting-started/concepts#checkpoint), and [shared memory](/docs/getting-started/concepts#shared-memory) connected when you switch agents.

## Start with a built-in agent

Atlas includes these agents in the switcher:

- [Claude Code](/docs/agents/claude-code)
- [Codex](/docs/agents/codex)
- [OpenCode](/docs/agents/opencode)
- [Cursor](/docs/agents/cursor)
- [Kilo Code](/docs/agents/kilo-code)
- [Atlas Agent](/docs/agents/atlas)

Claude Code and Codex have the deepest Atlas integration.

## Add another agent

Install any compatible Agent Client Protocol agent from [Discover agents](/docs/agents/registry). Atlas adds it below the built-in agents and gives it the same project context.

Every agent you run can work in the project you opened, add sessions to the timeline, link its commits to checkpoints, and read shared memory. An agent you installed moments ago can use context your team already built.

## Handle sign-in and models

Agents keep their own authentication and model choices. Atlas offers setup help for built-in agents; for registry agents, use the repository or website linked from the agent card.
