Atlas runs Cursor's coding agent through its ACP-enabled CLI. It does not embed Cursor's editor.

## Install and sign in

Install the [Cursor CLI](https://cursor.com/cli), then relaunch Atlas. Sign in with `cursor-agent login` in a terminal.

Atlas also surfaces Cursor's own sign-in flow, but the CLI login is the reliable path.

## Choose a model or mode

Cursor provides its model list when a session starts. Select one from the composer, then choose **agent**, **plan**, or **ask** mode.

## Resume your work

Atlas records every Cursor session in your [timeline](/docs/source-control/timeline) and links its commits to [checkpoints](/docs/getting-started/concepts#checkpoint).

<Callout type="warn">
  Cursor reports a free-plan quota limit as an ordinary assistant message. If it starts replying about limits instead of working, the quota is exhausted.
</Callout>

<Callout type="info">
  Atlas verified this behaviour with Cursor CLI 2026.07.23. Later versions may differ.
</Callout>
