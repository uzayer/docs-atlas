If you already use the Codex CLI, choose Codex in Atlas and start working. Atlas uses the credentials you already have.

## Start Codex

Atlas launches Codex through `npx`, which fetches the ACP adapter on its first run. You only need Node.js. If Atlas cannot find it, it tells you and links to nodejs.org.

Atlas reads your login shell's `PATH`, so Node installed with nvm, fnm, volta, asdf, or Homebrew works when Atlas opens from the Dock.

## Sign in once

Codex inherits the ChatGPT login from your Codex CLI or an `OPENAI_API_KEY` from your environment. Atlas does not ask you to sign in again or keep a second credential.

If authentication fails, sign in with the Codex CLI, then return to Atlas.

## Choose a model or mode

Use the composer to choose the model and mode Codex advertises for the current session.

## Resume your work

Atlas keeps the session in your [timeline](/docs/source-control/timeline) and links its commits to [checkpoints](/docs/getting-started/concepts#checkpoint).

Unlike [Claude Code](/docs/agents/claude-code#resume-your-work), Codex does not provide an on-disk transcript Atlas can parse to rebuild a prior conversation.
