Open **Settings → Agents** to add compatible agents from the official [Agent Client Protocol](https://agentclientprotocol.com) registry.

## Find an agent

Search by name, ID, or description. Filter the catalogue to **All**, **Installed**, or **Not Installed**. Atlas refreshes stale data itself, but **Refresh** fetches the latest catalogue whenever you need it.

## Install or remove one

Select **Install** on an agent card. Binary agents download immediately and show their progress. `npx` and `uvx` agents download on their first run, so they need Node.js or [uv](https://docs.astral.sh/uv) then.

Installed agents appear in the switcher below the built-in agents. Select **Remove** to hide one from the switcher without deleting its existing sessions.

## Read the badges

**Built-in** marks an agent Atlas already includes: `claude-acp`, `codex-acp`, `opencode`, `cursor`, or `kilo`. Installing another copy would shadow the supported version.

**Unverified** means a binary download has no published checksum. Atlas verifies downloads whenever the registry supplies one. A missing badge is not a safety guarantee.

[Atlas Agent](/docs/agents/atlas) is not in the registry because it does not use ACP.

## Work offline

Atlas opens its cached catalogue first and refreshes in the background. You can browse cached results offline; installing still needs a network connection.

## Use the agent

Registry agents work in the same [project](/docs/getting-started/concepts#project), timeline, and shared memory as built-in agents. They manage their own authentication and model options, so use the repository or website on the agent card for setup help.
