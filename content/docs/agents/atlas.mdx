Choose Atlas Agent when you want an agent that works natively with Atlas. It needs no install and appears as **Atlas** in the agent switcher.

## Add a provider key

Atlas Agent brings no model of its own. Add a key in **Settings → Providers**, then choose a model from the composer.

Atlas supports Anthropic, OpenAI, Google, xAI, DeepSeek, Mistral, Groq, Together, Fireworks, DeepInfra, Cerebras, OpenRouter, Perplexity, and Cohere. Atlas stores keys locally and shows only their last four characters after you save them.

## Work with the agent

Atlas Agent can read and edit files, search the project, and run shell commands. It can also:

- Search shared memory while it works, rather than relying only on context added to the turn.
- Delegate a scoped task to a subagent and bring the result back.
- Run [skills](/docs/getting-started/concepts#skill).

Choose a reasoning effort to control its thinking budget. Turn on tool-output compression when long command output would crowd out useful context.

## Know the differences

Atlas Agent does not use ACP and is not listed in the [agent registry](/docs/agents/registry). It cannot accept image input yet: a pasted screenshot reaches it as a file path.

Its sessions still appear in your [timeline](/docs/source-control/timeline) and link to [checkpoints](/docs/getting-started/concepts#checkpoint), just like every other agent.
