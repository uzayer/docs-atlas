Kilo Code gives you a large model catalogue and restores complete sessions when you reopen them.

## Install and sign in

Install the CLI, then relaunch Atlas:

```bash
npm install -g @kilocode/cli
# or
brew install Kilo-Org/tap/kilo
```

Sign in with `kilo auth login` in a terminal.

## Choose a model or mode

Pick from Kilo's `provider/model` options in the composer. You can also set reasoning effort and choose the mode Kilo supplies for the session.

## Resume your work

Kilo restores the full transcript for a reopened [session](/docs/getting-started/concepts#session). Atlas uses Kilo's own session IDs, so the session you see in Atlas is the same one in Kilo's local database.

Atlas also links its commits to [checkpoints](/docs/getting-started/concepts#checkpoint) in your [timeline](/docs/source-control/timeline).

<Callout type="info">
  Kilo does not implement ACP terminal methods. Atlas shows shell calls and their output as tool content, not as an interactive terminal.
</Callout>

<Callout type="info">
  Atlas verified this behaviour with Kilo Code 7.4.20. Later versions may differ.
</Callout>
