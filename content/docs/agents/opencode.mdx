OpenCode speaks ACP natively. You can try it without an account because it includes free models.

## Install and sign in

Install the CLI from [opencode.ai](https://opencode.ai), then relaunch Atlas. To use your own provider account, run `opencode auth login` in a terminal.

## Choose a model or mode

OpenCode provides its available models when a session starts. Select one from the composer, then choose **build** or **plan** mode.

## Resume your work

OpenCode can list, resume, and fork its own sessions. It also accepts image input, so pasted screenshots reach the agent as images.

Atlas keeps an independent record in your [timeline](/docs/source-control/timeline) and links its commits to [checkpoints](/docs/getting-started/concepts#checkpoint).

<Callout type="info">
  Atlas verified this behaviour with OpenCode 1.3.15. Later versions may differ.
</Callout>
