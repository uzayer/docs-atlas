OpenCode speaks ACP natively (no adapter package in between) and it's the one agent here you can use without signing in to anything.

![An OpenCode session running in the Atlas chat panel](/screenshots/placeholder.svg)

## Install

Install the OpenCode CLI from [opencode.ai](https://opencode.ai), then relaunch Atlas. If Atlas can't find it, the error says so and links you there.

## Sign in

Optional. `opencode auth login` connects your own provider account, but an unauthenticated install still works: OpenCode ships free models you can use immediately. That makes it a reasonable first agent to try if you don't have credentials for anything else yet.

## Models

OpenCode advertises its model list when a session starts, and Atlas switches between them through the composer's model picker.

## Modes

Two modes, **build** and **plan**, offered when the session starts and switchable from the composer.

## Sessions

OpenCode keeps its own session history and supports loading a previous session back over the protocol, along with listing, resuming, and forking. It also accepts image input, so pasted screenshots reach the agent as images rather than file paths.

As with every agent, Atlas records the session in your [timeline](/docs/getting-started/concepts#timeline) independently of whatever the agent keeps, and links commits made during it to that session as [checkpoints](/docs/getting-started/concepts#checkpoint).

<Callout type="info">
  This behaviour was verified against OpenCode 1.3.15. It's a fast-moving CLI. Later versions may differ.
</Callout>
