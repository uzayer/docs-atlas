Run Review on a change when you want a model other than the authoring agent to inspect it.

## Pick what to review

Choose uncommitted work, staged work, a commit, or a branch. You can also begin from a commit in [Source Control](/docs/product/git).

Choose the provider and model in [Settings → API Keys](/docs/product/settings), so one vendor's model can review another's output.

## Read the report

Review gives you an overall summary, risk score, effort estimate, security and test notes, and an architecture diagram when the change warrants one.

Each file gets a summary, risk level, and findings linked to the relevant lines. Files the review skipped are listed explicitly. Every run also records token use and cost.

## Turn feedback into work

Send a report, or one file's findings, into a [chat](/docs/product/chat) to give an agent the full review context. Copy reports as markdown or reopen a saved review without paying to run it again.
