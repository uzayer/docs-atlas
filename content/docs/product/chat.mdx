Open a chat to work with one [agent](/docs/getting-started/concepts#agent). Atlas records the conversation as a [session](/docs/getting-started/concepts#session), including its file reads, commands, and edits.

## Start or resume a session

Press `⌘T` for a new chat. Open the agent sidebar with `⌘⌥J`, or use the chat header, to search past sessions.

When you reopen one, Atlas paints the transcript from disk while the agent reconnects. A session belongs to one agent. Switching agents either changes an empty chat, saves and resets a chat with history, or opens a fresh tab when the current turn is still running.

## Give the agent direction

Use the composer to choose the agent, permission mode, model, and reasoning effort. `Enter` sends, `Shift+Enter` adds a line, and `⌘Enter` always sends.

Type `@` to add files, folders, symbols, notes, pack components, repositories, projects, papers, branches, or previous messages as context. Atlas shows larger references below your message so you can see what the agent receives.

Type `/` to run an agent command. Atlas passes most commands through unchanged, while a few open Atlas features.

## Steer a running turn

Messages you write while an agent works join a queue. Edit or remove them before they run. Plans appear above the composer, and permission requests show the agent's own choices.

Stop is always available. For a transient provider failure, Atlas shows the retry countdown and reason.

## Review the result

Every turn ends with a summary of time, token use, and changed files. Open the diff, jump to a file, reveal it in Finder, or ask Atlas to draft a commit message for your confirmation.

Search long sessions with `⌘F`. The Bash and Plans panels collect commands and plans without expanding the transcript.
