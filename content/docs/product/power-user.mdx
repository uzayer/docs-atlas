Atlas is meant to be the whole surface for a session. The faster you move through the rest of the app, the more of the work actually happens inside Atlas instead of around it.

## Shortcuts

These are Atlas's default shortcuts, with macOS labels. On Windows and Linux, <Kbd>Ctrl</Kbd> takes the place of <Kbd>⌘</Kbd> and <Kbd>Alt</Kbd> the place of <Kbd>⌥</Kbd>. **Settings → Keybindings** shows the bindings active on your device, and lets you change any of them.

## Command palette

Press <Kbd>⌘K</Kbd> to open the command palette. It opens on **Actions**, which covers a new session in the current project, a new session in another project, going to a file, searching the project, adding or creating a project, changing the theme or appearance, pull requests, Usage and Settings. **Recent Sessions** comes next. Each session shows its project, whether it runs locally or in a worktree, its agent and how long ago it was last active. Below that are the project, open, layout and split commands.

Type to search actions, projects and sessions together. A session whose title matches comes before one that only matches its project, and newer sessions come first. Start the query with `>` to search commands only. A row with an arrow, such as **Change theme** or **New session in…**, opens a list of its own. Press <Kbd>Backspace</Kbd> on an empty query, or <Kbd>Esc</Kbd>, to go back. Use <Kbd>↑</Kbd> and <Kbd>↓</Kbd> to move, <Kbd>Enter</Kbd> to run the highlighted row, and <Kbd>Esc</Kbd> to close the palette.

## Go to file

Press <Kbd>⌘P</Kbd>, or choose **Go to file** in the command palette, to find a file in the current project by name or path. Before you type, it lists the files open in tabs, then the files you opened recently. Each file shows its [icon theme](/docs/themes/icon-themes) icon, and the letters that match in its name are brighter than the rest. **Reindex** rebuilds the file list. If you opened it from the command palette, <Kbd>Esc</Kbd> takes you back to the palette with your query as you left it.

## Menu bar

Every command in the menus is also an action you can bind. On macOS the menus sit in the system menu bar: **Atlas**, **File**, **Edit**, **View**, **Window** and **Help**. On Windows and Linux the same menus are in Atlas's window bar. Each item shows the shortcut you have bound to it, so a binding you change in **Settings → Keybindings** shows up in the menu at once.

## Use another editor's keys

If your hands already know another editor, start from its keys. In **Settings → Keybindings**, set **Keys from** to **VS Code**, **Cursor**, **Zed** or **JetBrains**. Atlas also asks the first time it starts.

A preset only changes commands that editor has a well-known key for, such as <Kbd>⌘⇧P</Kbd> for the command palette under VS Code. Everything else keeps Atlas's default.

Your choices live in a profile, which you can copy as JSON and share. You can also limit where any shortcut works with a **When** condition. See [Settings → Keybindings](/docs/product/settings#keybindings).

## Click without the mouse

Press <Kbd>⌘⌥Space</Kbd> and Atlas puts a short label on every button, tab and field you can see. Type a label to click that element. <Kbd>Backspace</Kbd> removes a typed letter and <Kbd>Esc</Kbd> cancels.

## Rearrange the window

The bar along the top of the window is made of the columns' own headers.

The main column holds the session you are working in. Its header shows where you are, `organization / project / session title`, and never shows tabs. Switch sessions from the sidebar; click the session title to search for one. The header's buttons, from the left, show or hide [team chat](/docs/team/chat), show or hide the [session context](/docs/product/chat#session-context) card, and, while the surfaces pane is hidden, show it again.

Every tool opens in one of two places. A **surface** is a tool you use beside the session, as a tab in the surfaces pane: the editor, terminals, the browser, diffs, source control, team chat, PDFs and media, logs and prompt drafts. A **destination** is a full page you go to: Timeline, Usage, Knowledge, the knowledge graph, Memory and Spaces.

### Surfaces

Files, editors, terminals, the browser, team chat and the other surfaces open in the surfaces pane beside the session. It has its own tab strip and a **+** menu for opening another surface. Middle-click a tab to close it, or right-click it to close it, the others, the ones to its right or all of them, or to copy a file's path. Drag a tab sideways to move it along the strip; Atlas keeps the new order for the project, and <Kbd>⌘1</Kbd>–<Kbd>⌘9</Kbd> follow it. A tab stays in its own column. When the tabs do not fit, the strip scrolls: an edge with more tabs past it fades, arrows appear beside the strip, and the tab you switch to is always scrolled into view. The **+** and the buttons after it never scroll away. The strip ends in three buttons:

- **Maximize panel** gives the pane the whole center of the window, in place of the session, until you choose **Restore panel size**.
- **Dock panel at the bottom** and **Dock panel on the right** put the pane under or beside the session. Atlas remembers where you put it. Click the lit one to hide the pane.

Hiding the pane keeps its tabs running. Each surface has a minimum width, so a column will not resize narrower than its tool can use; team chat's is 320px.

Press <Kbd>⌘T</Kbd> to open a surface. Atlas opens the pane if it is closed, then shows the list of surfaces. Press a single letter to pick one:

| Key | Surface |
| --- | --- |
| <Kbd>A</Kbd> | Agent, another session beside this one |
| <Kbd>T</Kbd> | Terminal |
| <Kbd>B</Kbd> | Browser |
| <Kbd>N</Kbd> | New file |
| <Kbd>G</Kbd> | Source control |
| <Kbd>C</Kbd> | Team chat |
| <Kbd>L</Kbd> | Log |

So <Kbd>⌘T</Kbd> then <Kbd>T</Kbd> opens a terminal, and <Kbd>⌘T</Kbd> then <Kbd>G</Kbd> opens [source control](/docs/source-control/git). Press <Kbd>⌘\\</Kbd> to split the surfaces pane into another column.

### Destinations

Timeline, Usage, Knowledge, the knowledge graph, Memory and Spaces are full pages. Open one from the icons at the bottom of the sidebar (**Timeline**, **Knowledge**, **Memory**, **Usage**), from <Kbd>⌘K</Kbd>, with its shortcut (<Kbd>⌥J</Kbd> for Knowledge), or, for a conversation's Space, with its **Spaces** button. It takes the area right of the sidebar, and the bar reads `organization / project ‹ Timeline`. The session keeps running underneath.

Only one destination shows at a time; opening another replaces it. To get back to the session, press <Kbd>Esc</Kbd>, select the back arrow (**‹** and the page's title) in the bar, or use the same sidebar icon or shortcut again. Opening or focusing any session or surface also takes you back. The page stays as you left it, so returning to it is instant.

### Layouts

Press <Kbd>⌘⌥L</Kbd> to apply a layout. Each one puts the session first:

- **Focus**: just the session; open tools stay running, out of sight
- **Develop**: the file tree, the session and an editor
- **Terminal**: the session next to a terminal, with the file tree
- **Review**: the session with source control beside it

Press <Kbd>⌥Z</Kbd> for zen mode: the session beside a browser, in two columns, with the side panels hidden. Press it again to return to the layout you had.

## Open a folder from your terminal

The `atlas` command opens a folder as a project, the way `code .` does for VS Code:

```bash
atlas .            # open the current folder
atlas ./some-dir   # open another folder
atlas --version    # print the Atlas version
```

Atlas installs it at `~/.local/bin/atlas` on macOS and Linux and refreshes it on every launch. If your shell cannot find it, add `~/.local/bin` to your `PATH`. You can reinstall it from **Atlas CLI** in Settings → General.

## `@` mentions

Type `@` in any composer to pull something into context without leaving the keyboard:

- **file** / **folder**: anything in the project
- **symbol**: a function, class, or other code symbol
- **note**: a [knowledge base](/docs/getting-started/concepts#knowledge-base) note
- **component**: a command, subagent, or rule installed from a [pack](/docs/getting-started/concepts#pack)
- **repo**: a cloned GitHub repository
- **project**: another project
- **branch**: a git branch
- **past message** / **past session**: anything earlier in this session, or an earlier one

In a project shared with your organization through [cloud capture](/docs/source-control/capture), you can also mention:

- **member**: a teammate
- **conversation**: a team chat channel or direct message
- **recorded session**: a session on the team [timeline](/docs/team/timeline)
- **comment**: a comment on a recorded session

These are sent as links rather than copied in, so an agent with access to your organization, such as [Atlas Agent](/docs/agents/atlas-agent), can look them up.

Type `~` instead of `@` to open the same picker scoped to just the knowledge base, the same shortcut the notes editor uses.
