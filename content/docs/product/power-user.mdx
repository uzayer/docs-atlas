Atlas is meant to be the whole surface for a session. The faster you move through the rest of the app, the more of the work actually happens inside Atlas instead of around it.

## Shortcuts

These are Atlas's default shortcuts, with macOS labels. On Windows and Linux, <Kbd>Ctrl</Kbd> takes the place of <Kbd>⌘</Kbd> and <Kbd>Alt</Kbd> the place of <Kbd>⌥</Kbd>. **Settings → Keybindings** shows the bindings active on your device, and lets you change any of them.

## Use another editor's keys

If your hands already know another editor, start from its keys. In **Settings → Keybindings**, set **Keys from** to **VS Code**, **Cursor**, **Zed** or **JetBrains**. Atlas also asks the first time it starts.

A preset only changes commands that editor has a well-known key for, such as <Kbd>⌘⇧P</Kbd> for the command palette under VS Code. Everything else keeps Atlas's default.

Your choices live in a profile, which you can copy as JSON and share. See [Settings → Keybindings](/docs/product/settings#keybindings).

## Click without the mouse

Press <Kbd>⌘⌥Space</Kbd> and Atlas puts a short label on every button, tab and field you can see. Type a label to click that element. <Kbd>Backspace</Kbd> removes a typed letter and <Kbd>Esc</Kbd> cancels.

## Rearrange the window

Press <Kbd>⌘⌥L</Kbd> to apply a layout: **Focus** (just the agent), **Develop** (files, editor and agent), **Research** (knowledge, agent and the web side by side), **Terminal** (agent next to a terminal, with the file tree), **Review** (agent with the review panel) or **Usage**.

Press <Kbd>⌥Z</Kbd> for zen mode: the knowledge base, an agent chat and a browser in three columns, with the side panels hidden. Press it again to return to the layout you had.

## Open a folder from your terminal

The `atlas` command opens a folder as a project, the way `code .` does for VS Code:

```bash
atlas .            # open the current folder
atlas ./some-dir   # open another folder
atlas --version    # print the Atlas version
```

Atlas installs it at `~/.local/bin/atlas` on macOS and Linux and refreshes it on every launch. If your shell cannot find it, add `~/.local/bin` to your `PATH`. You can reinstall it from **Atlas CLI** in Settings → General.

## `@` mentions

Type `@` in any composer to pull something into context without leaving the keyboard:

- **file** / **folder**: anything in the project
- **symbol**: a function, class, or other code symbol
- **note**: a [knowledge base](/docs/getting-started/concepts#knowledge-base) note
- **component**: a command, subagent, or rule installed from a [pack](/docs/getting-started/concepts#pack)
- **repo**: a cloned GitHub repository
- **project**: another project
- **branch**: a git branch
- **past message** / **past session**: anything earlier in this session, or an earlier one

In a project shared with your organisation through [cloud capture](/docs/source-control/capture), you can also mention:

- **member**: a teammate
- **conversation**: a team chat channel or direct message
- **recorded session**: a session on the team [timeline](/docs/team/timeline)
- **comment**: a comment on a recorded session

These are sent as links rather than copied in, so an agent with access to your organisation, such as [Atlas Agent](/docs/agents/atlas-agent), can look them up.

Type `~` instead of `@` to open the same picker scoped to just the knowledge base, the same shortcut the notes editor uses.
