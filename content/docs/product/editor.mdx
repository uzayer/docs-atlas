Open files in tabs at the centre of Atlas. Use the editor to follow an agent's changes and make a correction yourself.

## Read any file

Atlas loads syntax highlighting when it knows the language. Files without a grammar still open as readable plain text. Markdown opens rendered rather than as source.

## Review git context

Change bars mark lines added, changed, or deleted since `HEAD`. Turn on inline blame in [Settings → General](/docs/product/settings) to see the author, time, and commit summary for the line under your cursor.

## Work safely with an agent

Atlas reloads an open file when the agent changes it and you have no unsaved edits. If you do have edits, Atlas keeps your buffer intact and offers **Reload** when you are ready to discard them.

Atlas never overwrites unsaved work.

## Change the look

Choose editor themes separately from the interface theme in [Settings → Appearance](/docs/product/settings). Switching themes keeps your open buffers and undo history.
