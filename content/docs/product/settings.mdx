Press <Kbd>⌘,</Kbd> to open Settings in a tab.

## Set the essentials

**General** controls sending behaviour, `.atlas` gitignore setup, hidden files, inline blame, Atlas logs, privacy-preserving usage data, follow-up suggestions, the Atlas CLI, and model pricing.

Use **Appearance** for the one theme that colours all of Atlas, **Icons** for file and folder icons, and **Layouts** for saved panel arrangements. Press <Kbd>⌘⌥L</Kbd> to switch layouts anywhere. See [Themes](/docs/themes) for both theme tracks.

## Add integrations

Use **API Keys** for Atlas Agent, commit-message drafting, and Review. Atlas stores keys locally and shows only their last four characters after you save them.

Use **Skills** to manage skills and packs, **Agents** to manage the agent registry, and **Local Models** to download embedding models for code indexing and memory retrieval.

Changing the embedding model rebuilds the index after Atlas asks for confirmation.

## Finish the setup

Use **Updates** to choose automatic updates or check manually. Use **Keybindings** for the full shortcut reference. **About** shows version information.
