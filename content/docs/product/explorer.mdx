Files is a surface beside your session. Press <Kbd>⌘B</Kbd> to show or hide it, or open it with <Kbd>⌘T</Kbd> then <Kbd>F</Kbd>, **Show files** in the command palette, or **Files** in the review panel's header. Each project has one; opening it again brings it forward. Atlas watches your project, so files an agent creates, renames, or deletes appear without a refresh.

The tree stays quick in very large projects. It loads a folder the first time you open it and only draws the rows on screen.

## Search files

Type in **Search files** at the top of the tree. The tree narrows to the files whose path contains what you typed, with their folders opened and the match in bold. Press <Kbd>↓</Kbd> to move into the results and <Kbd>Esc</Kbd> to clear the search. Opening a result keeps the search in the tree beside that file.

Refresh and **Collapse All** sit on the same row. A chain of folders that each hold a single folder shows as one row, such as `vendor / atlas-engine`.

## Open a file

Click a file to open it in a tab. The tab keeps the project tree beside the file, with the file highlighted, so you can move on to the next one from there. Hide the tree with **Hide file tree** and Atlas remembers the choice. A file outside the project opens without the tree.

A file with uncommitted changes shows its added and removed lines. Right-click it and choose **Open Changes** to jump to its diff in the [review panel](/docs/source-control/git#read-a-diff).

## Find changed files

Atlas colors files by git status: added, modified, deleted, renamed, conflicted, or untracked. Collapsed folders take the most serious status beneath them. Files your `.gitignore` excludes are dimmed.

## Select and move files

Click to select, <Kbd>⌘</Kbd>-click to add, and <Kbd>⇧</Kbd>-click to extend a selection. Drag files or folders onto another folder to move them, or drop files from your system file manager to copy them in.

## Use the context menu

Right-click a row to work with it:

- create a **New File** or **New Folder** inside a folder
- **Open** a file, or **Open in Default App** to hand it to your system. A program is shown in Finder instead of run.
- **Open in** your editor, or **Open With** to pick another editor Atlas found on your computer
- **Open Changes** to see a changed file's diff
- **Open in Terminal** to start a shell in a folder
- **Reveal in Finder** to show it in your system file manager
- **Cut**, **Copy**, **Duplicate**, **Paste**, **Rename** or **Delete**
- **Copy Path** or **Copy Relative Path**
- **Add to .gitignore**

With several rows selected, **Cut**, **Copy**, **Delete** and the copy-path items act on all of them. Right-click empty space to create at the project root, paste, reveal the project, open a terminal there, or **Collapse All**.

## Show hidden files

Atlas shows dotfiles by default. Turn off **Show hidden files** in [Settings → General](/docs/product/settings#general) when you want a cleaner tree.
