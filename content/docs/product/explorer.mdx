The left panel (`⌘B`) holds the file tree for your [project](/docs/getting-started/concepts#project). It watches the filesystem, so an agent creating, renaming, or deleting files shows up without a refresh: there is no refresh button because there is nothing to refresh.

## Git status

Changed files are coloured by their status: added, modified, deleted, renamed, conflicted, untracked. A collapsed folder takes the colour of the most serious change anywhere beneath it, so you can find the interesting part of a tree without expanding it.

## Selecting and moving

Click selects, `⌘`-click adds, `⇧`-click extends (the usual Finder behaviour), and every context-menu action applies to the whole selection.

Dragging a file or folder onto another folder moves it. Hovering over a collapsed folder mid-drag expands it. Dropping files in from Finder copies them in.

## Context menu

Right-click a row for: **New File** and **New Folder**, **Open in Terminal**, **Cut** / **Copy** / **Duplicate** / **Paste**, **Copy Path** and **Copy Relative Path**, **Add to .gitignore**, **Rename**, and **Delete**. Right-clicking empty space gives you the same creation actions against the project root, plus **Reveal Project in Finder** and **Collapse All**.

## Hidden files

Dotfiles and dot-directories are shown by default, so nothing about your project is quietly invisible. Turn them off in [Settings → General](/docs/product/settings) for a cleaner tree.
