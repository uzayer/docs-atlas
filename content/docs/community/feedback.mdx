Short or long, polished or rough, we read all of it. Pick whichever of these is closest to hand.

| You want to | Use |
| --- | --- |
| Tell us something quickly, from inside Atlas | [Send feedback](#from-the-app) in the app |
| Report a bug others can follow | [GitHub issues](#github-issues) |
| Ask a question or talk it through | [Discord](#discord) |
| Work with the team as a beta tester | [atlas-beta](#atlas-beta) |
| Report a security problem | [The security policy](#security-problems) |

## From the app

Select the **?** at the bottom of the rail, then **Send feedback**. It is also in **Settings → General**. A panel opens in the bottom-right corner, and stays out of the way so you can still see what you're describing.

1. Choose **Issue**, **Feature request**, **Improve** or **Other**.
2. Write as much or as little as you like.
3. On macOS, select **Attach screenshot** to drag a region, or press Space and click to capture the whole Atlas window.
4. Select **Send**, or press <Kbd>⌘</Kbd> <Kbd>Enter</Kbd> (<Kbd>Ctrl</Kbd> <Kbd>Enter</Kbd> on Windows and Linux).

When you're signed in, the footer shows whether you're **Sending as** your account or **Sending anonymously**; select it to switch. Signed out, feedback is always anonymous. It is sent even when usage data is turned off, because you asked for it to be.

The panel's footer also has **Open a GitHub issue**, which opens the matching GitHub form with what you've typed already filled in, and **Join the community**, which opens Discord. Closing the panel with <Kbd>Esc</Kbd> or the close button keeps your draft.

## GitHub issues

[github.com/pacifio/atlas/issues](https://github.com/pacifio/atlas/issues) is the public record of bugs and requests. Two forms:

- **[Bug Report](https://github.com/pacifio/atlas/issues/new?template=bug_report.yml)**, for something broken.
- **[Feature Request / Feedback](https://github.com/pacifio/atlas/issues/new?template=feedback.yml)**, for an idea or something that feels clumsy.

Each form needs only a description. A one-line note is a fine issue. Search first, and react to an existing issue instead of filing a duplicate.

For what makes a bug report easy to act on, especially attaching the agent session, see [Report a bug](/docs/community/beta-testing#report-a-bug).

## Discord

The [Atlas Discord](https://discord.gg/GmnFggaPfP) is open to everyone. Ask questions in `#dev`, and bring ideas to `#feature-requests`.

## atlas-beta

Beta testers talk with the team in the **atlas-beta** organization, inside Atlas: its [team chat](/docs/team/chat) channels, calls and prompt drafts. Code contributors are in atlas-beta too; see [Contributing](/docs/community/contributing). See the [Beta program](/docs/community/beta-program) for how to join.

## Security problems

Don't report a vulnerability in a public issue, on Discord or in chat. Follow the [security policy](https://github.com/pacifio/atlas/security/policy) to report it privately.
