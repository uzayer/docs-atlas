Search academic literature, save a paper to the project, and give the source to an agent when you need it.

## Find a paper

Search **arXiv** or **Semantic Scholar**. Results include the title, authors, abstract, publication date, categories, and links to the paper and PDF.

## Use it in a chat

Download a paper to save it in the project. Type `@` in the [composer](/docs/product/chat) and select it to give the agent the same visible context block you use for a file.
