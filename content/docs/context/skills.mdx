Use a [skill](/docs/getting-started/concepts#skill) to give an agent a named instruction it can invoke. Use a [pack](/docs/getting-started/concepts#pack) to install several skills, commands, agents, rules, hooks, or scripts together.

Manage both in **Settings → Skills**.

## Choose the scope

Make a skill **global** to use it in every project, or **project** to keep it in one. Enable each skill only for the agents that should receive it.

Atlas keeps one canonical copy and links it into each agent's own skills directory. A skill uses no context until the agent invokes it. You can also adopt an existing agent-specific skill into Atlas so it works across agents.

## Install a pack

Search the skills.sh registry, preview a pack, then install it. Atlas fetches the source repository, tracks the installed version in a lockfile, and can check for updates.

Skills become invokable instructions. Commands, agents, and rules from the pack become items you can [mention](/docs/getting-started/concepts#mention) in the composer.

## Invoke a skill

Type `/` in the [composer](/docs/product/chat) and choose a skill the current agent advertises.

<Callout type="info">
  A passthrough command runs only when it starts the message. Atlas sends it as ordinary text when it appears mid-sentence.
</Callout>
