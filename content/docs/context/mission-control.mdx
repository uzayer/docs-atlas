Use Mission Control to see where agent time and money went across every project you have opened in Atlas.

## Review your usage

Choose 7, 30, or 90 days, or view everything. Atlas shows totals for tokens, requests, sessions, and estimated cost, then breaks them down by date and project.

The dashboard also includes a per-project activity timeline and a log table for the detail behind each number. Where a provider reports them, token totals include cache reads and writes.

<Callout type="info">
  Mission Control currently tracks Claude Code, Codex, and [Review](/docs/product/review) runs. Atlas records other agents in your [timeline](/docs/source-control/timeline), but they do not report the usage data this dashboard needs.
</Callout>

## Export a report

Export the current view as a PDF, image, or markdown file.
