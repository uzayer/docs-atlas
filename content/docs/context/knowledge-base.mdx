Use the knowledge base for facts and decisions you want to write down deliberately. Atlas stores these markdown notes in your project's directory and indexes them alongside [memory](/docs/context/memory).

## Write a note

Open the knowledge base from the left panel. The block editor gives you headings, lists, an outline, properties, icons, and covers. Press `⌘S` to save.

Use the sidebar to move through notes. Press `⌘'` to inspect the current note and `⌘;` to show or hide the sidebar. Notes can link to each other and show their backlinks.

## Give a note to an agent

Type `@` in the [composer](/docs/product/chat) and select a note. Atlas appends its contents as a visible context block, so you know exactly what the agent received.

Atlas also indexes notes, so relevant information can surface without an explicit mention.
