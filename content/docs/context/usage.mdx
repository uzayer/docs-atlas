Use Usage to see where tokens, messages, sessions, and estimated cost went across the active organisation's projects.

## Review your usage

Choose 7, 30, or 90 days, a custom range, or view everything. Atlas shows totals for tokens, messages, sessions, and estimated cost, then lets you group and filter the data by project, agent, or model.

The dashboard includes a daily series, efficiency and cache metrics, and searchable tables for sessions, projects, agents, and models. Where an agent reports them, token totals include cache reads, cache writes, and reasoning tokens.

<Callout type="info">
  Usage reads Atlas's own captured session record, so it is not limited to a fixed list of agents. An agent contributes token detail only when its ACP implementation reports usage. An unknown or unpriced model still contributes recorded tokens but has no invented fallback cost.
</Callout>

## Export a report

Export the current view as a PDF, JPEG, or markdown file, or copy the markdown report.
