Use Usage to see where tokens, messages, sessions and estimated cost went across the active organization's projects. Open **Usage** from the rail.

## Review your usage

Choose 7, 30 or 90 days, a custom range, or everything. Atlas shows totals for tokens, messages, sessions and estimated cost.

Below the totals:

- a daily chart you can group by **Project**, **Agent** or **Model**, showing **Tokens**, **Cost** or **Messages**
- filters for one project, agent or model
- efficiency figures: cache hit rate, output to input ratio, and tokens per session
- searchable, sortable tables of sessions, projects, agents and models

Where an agent reports them, token totals include cache reads, cache writes and reasoning tokens. Estimated cost uses per-model prices from models.dev, in US dollars.

<Callout type="info">
  Usage reads Atlas's own record of the sessions on this machine, so it is not limited to a fixed list of agents. An agent contributes token detail only when its ACP implementation reports usage. An unknown or unpriced model still contributes recorded tokens but has no invented fallback cost.
</Callout>

## See your team's usage

This tab covers the sessions you ran on this machine. Your organization's spend on Atlas Agent, broken down by person and held to budgets, is in the web app. See [AI access & spend](/docs/team/ai-access).
